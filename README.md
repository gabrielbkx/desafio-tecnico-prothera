# Teste Prático

Solução do teste prático em Java focado em Orientação a Objetos, Coleções (List, Map) e Streams API. Todos os requisitos da prova foram implementados na classe principal.

## 🛠️ Tecnologias
- Java (Collections, Streams, Lambda)
- Manipulação de `LocalDate` e `BigDecimal`
